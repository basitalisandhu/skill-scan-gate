# Roadmap

This is what we are working on and what we would like help with, in plain order. It is a list of intentions, not promises: there are no dates, and the order changes when people show up or the evidence changes. Every item links an issue. Comment there to claim it or to argue for a different order, or vote in the [Roadmap discussion](https://github.com/basitalisandhu/skill-scan-gate/discussions).

## Not planned

- Executing anything it scans, or making network calls while scanning.
- Replacing a human review of a skill. It is a gate that catches known-bad patterns, not a proof of safety.

Want to add something? Open an issue describing the problem first, with what done looks like. The [CONTRIBUTING.md](CONTRIBUTING.md) file explains the rest.
